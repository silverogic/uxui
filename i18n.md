# Internationalization (i18n)

- **Design for Multilingual Support:** Write UI code and layouts with multilingual expansion and varying string lengths in mind.
- **Regional Default Language:** For web applications, display the language corresponding to the user's access region by default; otherwise, fall back to English.
- **Locale-Aware Numeric & Unit Formatting:** Beyond text translation, localize numeric scales, currency multipliers (e.g., `100 JPY`, `1,000 KRW`), and compact unit suffixes (e.g., `T`/`B` vs. `조`/`억`) at the formatter level so quantitative data remains natural in every supported locale.
